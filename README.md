# குடிப்பழக்கத்தின் புரிதல் (Kudipazhakkathin Purithal)
Calm Tamil de-addiction awareness PWA. React + Vite + Tailwind, offline, localStorage only.

Run: `npm install && npm run dev`  ·  Build: `npm run build`

Edit content in `src/App.jsx` (VIDEOS: add a YouTube id as `yt: 'VIDEO_ID'`, CONCEPTS, SOCIAL) and `src/Journey.jsx` (TASKS, WEEKS).
Deploy: push to `main`, then GitHub → Settings → Pages → Source: GitHub Actions.
